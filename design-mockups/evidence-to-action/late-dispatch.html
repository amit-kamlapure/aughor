    The most complicated page by code (Dashboards: 12.1k lines, 35 files), on theLook's ontology dashboard. Every figure was read live from the API on 9 Nov 2026 23:10 UTC; nothing on the page is invented. Today's page is at the bottom for comparison.
    
  
    
    
    
      
    What following the doc changed on this page
    
      
      
        
    1. Light first (§5), with the doc's dark tokens on the corner toggle. The doc's blue-teal accent is replaced by one you pick in the corner (indigo by default, or blue or slate). All are contrast-checked in both skins.
      2. 
        
    2. Seven destinations, with the Aughor-safe names now built (Define, Operations). This page sits under Analyze › Dashboards.
      3. 
        
    3. Chrome: a 52px top bar plus breadcrumb, title, tabs and toolbar rows (222px), and a 28px status strip. Today's page uses 214px before the first widget, so the totals are about the same, just split into named rows.
      4. 
        
    4. The process board's four figure boxes became two tables: stages, and promises ranked by open and overdue. No figure is above 15px (§5.5, §13.3, §20).
      5. 
        
    5. The Order detail and Flag for review widgets left the canvas. Selecting a row opens the one inspector. The action is a Propose on the grid toolbar and in the inspector's Actions tab, following the doc's lifecycle.
      6. 
        
    6. Every widget says cached or live, with a UTC time. That puts on screen something today's page hides. The process table's 25,186 is cached from 8 Nov 22:28 UTC; the list's 24,654 is read live. The delivery promise is measured "as of 14 Nov", after today.
      7. 
        
    7. Values say what they are: null rather than "—", and timestamps written in full with their zone (§6.2, §9.1).
      8. 
        
    8. The Provenance tab shows what the API already returns: SQL, count SQL, plan, timing, completeness, run-as. It says not recorded for the query and execution IDs the doc requires, because object reads keep none.
      9. 
        
    9. Edit mode has separate Canvas and Data views (§14.1). The "In words" composer moved into the inspector's Assist tab (AI lives only there). Below 1600px, Outline and the inspector can't both be open (§4.3–4.4).
      10. 
        
    10. The inspector's Relations tab shows two links with the same rule (Order placed by User, order_to_user and placed_by). The doc's honesty brings that duplicate to the surface.
